# 池化与采样

## 采样（Upsample）

```Python
import torch
from torch import nn

x = torch.rand(1,16,14,14)

layer = nn.MaxPool2d(2,stride = 2)
# 建立一个采样实例 尺寸为2 * 2 步进为 2

out = layer(x)
out.shape
Out[8]: torch.Size([1, 16, 7, 7])
```

## 插值（`F.interpolate`）

```Python
import torch.nn.functional as F

x = torch.rand(1,16,7,7)

out = F.interpolate(x,scale_factor = 2,mode='nearest')
out.shape
Out[16]: torch.Size([1, 16, 14, 14])
# 将图片每个点扩大两倍 2 * 2（1点变4点）

out = F.interpolate(x,scale_factor = 3,mode='nearest')
out.shape
Out[18]: torch.Size([1, 16, 21, 21])
# 将图片每个点扩大三倍 3 * 3（1点变9点）
```

## ReLU

```Python
layer = nn.ReLU(inplace = True)
# 因为输出图的大小与原图相等
# 所以inplace = True可以节约空间

out = layer(x)
out.shape
Out[22]: torch.Size([1, 16, 7, 7])

# 也可以直接使用 torch.nn.functional 中的函数直接调用
out = F.relu(x)
out.shape
Out[24]: torch.Size([1, 16, 7, 7])
```
