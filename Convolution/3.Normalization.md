# Normalization

## 作用

- 将图片的数值压缩到一定范围，在后面寻找最优解（梯度下降）的时候效率更高
- 加速神经网络的收敛

## Image Normalization

- 操作代码

```Python
import torch
from torchvision.transforms import transforms

normalize = transforms.Normalize(mean=[0.485,0.456,0.406],std=[0.229,0.224,0.225])

x = torch.rand(1,3,28,28)
out = normalize(x)
# out即为归一化之后的结果
```

## Batch Normalization

- 对所有图片的各个Channel进行统计均值和方差 并进行归一化处理

### BatchNorm1d

from torch import nn
layer = nn.BatchNorm1d(16) # 设定为16个channel
out = layer(x)
